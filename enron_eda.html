Enron Email Corpus: Exploratory Data Analysis¶

What this notebook does:

  1. Reads the raw Enron emails from our Data Lake bucket (dsan6000-enron-lake-n2h)
  2. Turns each email into one clean row (sender, recipients, date, subject, body...)
  3. Saves the clean table to our group Data Mart bucket (dsan6000-enron-mart-n2h)
  4. Answers basic "what does this data look like?" questions with tables and charts

First run: leave QUICK_TEST = True (reads only the first 25,000 emails, about a minute). When that works: set QUICK_TEST = False and click Run All again (all ~500K emails, about 15–20 min).

The emails are processed one chunk at a time, so this fits in the 8 GB of RAM on a t3.large.

def read_parquet_s3(bucket, key):
    obj = s3.get_object(Bucket=bucket, Key=key)

def write_parquet_s3(frame, bucket, key):
    buf = io.BytesIO()
    frame.to_parquet(buf, index=False)
    buf.seek(0)
    s3.upload_fileobj(buf, bucket, key)

1. How we parse one email¶

Each raw email has a header block (From:, To:, Date: ...), a blank line, then the body. Python's built-in email module splits these for us, and also undoes the quoted-printable encoding (the = line breaks and =20 shown in the vignette).

ADDR_RE = re.compile(r"^[a-z0-9._%+'-]+@[a-z0-9.-]+\.[a-z]{2,}$")

def clean_addresses(header_value, return_bad=False):
    """Turn a To/Cc/Bcc header into a list of clean, lowercase addresses.
    Drops junk like 'e-mail <.arm@enron.com>' that isn't a valid address."""
    out, bad = [], 0
    if header_value:
        for _, addr in getaddresses([str(header_value)]):
            addr = addr.strip().lower()
            if ADDR_RE.match(addr) and not addr.startswith("."):
                out.append(addr)
            elif addr:
                bad += 1
    return (out, bad) if return_bad else out

def get_body(msg):
    """Return the plain-text body, decoding quoted-printable if needed."""
    parts = msg.walk() if msg.is_multipart() else [msg]
    for part in parts:
        if part.get_content_type() == "text/plain":
            payload = part.get_payload(decode=True) or b""
            return payload.decode("latin-1", errors="replace")
    return ""

def parse_email(path, raw_text):
    msg = email.message_from_string(raw_text)
    try:
        dt = parsedate_to_datetime(msg["Date"])
        date = dt.replace(tzinfo=None)                              # sender's local clock time
        tz_offset = dt.utcoffset().total_seconds() / 3600 if dt.utcoffset() is not None else None
    except Exception:
        date, tz_offset = pd.NaT, None
    parts = path.split("/")                    # e.g. maildir/lay-k/inbox/28.
    mi = parts.index("maildir") if "maildir" in parts else 0
    to, bad_to = clean_addresses(msg["To"], return_bad=True)
    cc, bad_cc = clean_addresses(msg["Cc"], return_bad=True)
    bcc, bad_bcc = clean_addresses(msg["Bcc"], return_bad=True)
    body = get_body(msg)
    subject = str(msg["Subject"] or "")
    return {
        "message_id": msg["Message-ID"],
        "date": date,
        "tz_offset": tz_offset,
        "sender": (clean_addresses(msg["From"]) or [None])[0],
        "to": to,
        "cc": cc,
        "bcc": bcc,
        "n_bad_addresses": bad_to + bad_cc + bad_bcc,
        "x_from_exchange": "/O=ENRON" in str(msg["X-From"] or "").upper(),
        "has_reply_header": bool(msg["In-Reply-To"] or msg["References"]),
        "subject_re": bool(re.match(r"^\s*re\s*:", subject, re.I)),
        "subject_fw": bool(re.match(r"^\s*(fw|fwd)\s*:", subject, re.I)),
        "has_quoted_text": bool(re.search(r"-----\s*Original Message\s*-----|Forwarded by", body, re.I)),
        "subject": subject,
        "body": body,
        "quoted_printable": str(msg["Content-Transfer-Encoding"] or "").lower() == "quoted-printable",
        "mailbox": parts[mi + 1] if mi + 1 < len(parts) else None,   # e.g. 'lay-k'
        "folder": "/".join(parts[mi + 2:-1]),                        # e.g. 'inbox'
    }

2. Clean every chunk and save it to the Data Mart¶

For each raw file in the Data Lake (25,000 emails each):

  • parse every email into a row
  • remove duplicates: the same email is often saved in several folders and mailboxes, so two emails with the same sender, date, subject and body count as one
  • save the clean chunk to the Data Mart
  • keep a small version (no body text) in memory for the charts below
In [17]:
listing = s3.list_objects_v2(Bucket=DATA_LAKE, Prefix="enron/raw/")
keys = sorted(o["Key"] for o in listing.get("Contents", []) if o["Key"].endswith(".parquet"))
print(f"Found {len(keys)} raw files in s3://{DATA_LAKE}/enron/raw/")
if QUICK_TEST:
    keys = keys[:1]

seen = set()                     # hashes of emails we've already kept
body_chars = 0                   # total text size (for the embedding/search question)
small_parts = []                 # light columns for the EDA
mailbox_counts = pd.Series(dtype="int64")
n_files, n_errors = 0, 0

for i, key in enumerate(keys):
    chunk = read_parquet_s3(DATA_LAKE, key)
    rows = []
    for path, text in zip(chunk["path"], chunk["raw_text"]):
        try:
            rows.append(parse_email(path, text))
        except Exception:
            n_errors += 1
    n_files += len(chunk)
    del chunk

    df = pd.DataFrame(rows)
    del rows
    mailbox_counts = mailbox_counts.add(df["mailbox"].value_counts(), fill_value=0)

    key_str = df["sender"].fillna("") + "|" + df["date"].astype(str) + "|" + df["subject"] + "|" + df["body"]
    df["email_hash"] = key_str.map(lambda s: hashlib.md5(s.encode("utf-8", "replace")).hexdigest())
    df = df.drop_duplicates("email_hash")
    df = df[~df["email_hash"].isin(seen)]
    seen.update(df["email_hash"])

    df["n_recipients"] = df["to"].str.len() + df["cc"].str.len() + df["bcc"].str.len()
    df["body_words"] = df["body"].str.split().str.len()
    df["attachment_only"] = df["body"].str.strip().str.match(r"^-\s*\S+\.\w{2,4}$")

    body_chars += int(df["body"].str.len().sum())
    write_parquet_s3(df, DATA_MART, f"{OUT_PREFIX}/part-{i:04d}.parquet")
    small_parts.append(df.drop(columns=["body", "message_id"]))
    print(f"{key}: {len(df):,} unique emails kept (total so far {len(seen):,})")
    del df

emails = pd.concat(small_parts, ignore_index=True)
del small_parts
print(f"\nRaw files read: {n_files:,}   Parse errors: {n_errors}")
print(f"Unique emails: {len(emails):,}   Duplicates removed: {n_files - len(emails):,} "
      f"({1 - len(emails)/n_files:.0%})")
print(f"Clean table saved to s3://{DATA_MART}/{OUT_PREFIX}/")

Whose email do we actually have?¶

The corpus is ~150 employees' mailboxes, not the whole company. People outside those mailboxes only appear when they emailed one of them, so the network is incomplete at its edges.

Sent after hours or on weekends: 49.7%

Weekday email peaks between 7 and 9 am and drops sharply after 4 pm, with very little on weekends. The timestamps appear to be recorded in Pacific time while most Enron employees worked in Houston (Central time, 2 hours later), so the raw 49.7% "after hours" figure overstates late-night work and needs a time-zone correction before we use it as a workload signal.
