# Enron Email Corpus Analysis

**DSAN 6000 · Big Data and Cloud Computing**  
**Team:** Noelle Martell, Nkemdibe Okweye, and Hillary Metcheka

## Project Overview

We use the Enron Email Corpus to explore how employees communicated during the company’s collapse. Our project combines an analysis of the email network, a comparison of communication patterns among people identified as Persons of Interest (POIs), and a semantic search tool for exploring the emails.

## Repository Contents

- `ingest_enron.py` — Data ingestion script
- `enron_eda.ipynb` — Exploratory data analysis notebook
- `enron_eda.html` — HTML export of the EDA notebook

## Planned Work

1. **Communication network and workload**: Analyze who emailed whom, how communication patterns changed over time, and how workload indicators such as response times and after-hours email activity shifted around key events.
2. **Person of Interest (POI) communication patterns**: Compare the network positions, response behavior, and language of people labeled as POIs with those of other employees.
3. **Semantic search**: Build a tool that retrieves relevant Enron emails and their conversation threads from natural-language queries.
